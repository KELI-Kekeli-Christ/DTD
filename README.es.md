Clasificación de texturas few-shot y supervisada sobre el Describable Textures Dataset (47 clases). El README registra un 75,98 % de accuracy de test con ViT-B/16 en el split 1. Imágenes, etiquetas y `dtd_results` están en el repositorio. Lee `README.md` para las puntuaciones y las notas por clase. No hay un comando de entrenamiento en la raíz.


La documentación en inglés que ya estaba en este repositorio sigue en el archivo en inglés.
